# Claude skills used by this workflow (backup copies)

These skills live in the claude.ai account, not in the repo, and work in every
project once saved. The copies here are for reference and for setting up a new
account: in any chat ask "propose the skill from `claude-skills/<name>/SKILL.md`"
and save it from the review card.

| Skill | What it does |
|---|---|
| `session-handoff` | "commit the session" / "wrap up" / «зафиксируй» → backlog, STATUS, ADRs, learnings, runbooks, commit + push |
| `delegated-research` | Large web research (~8+ searches) done by a Haiku subagent; only a summary comes back |
| `chat-history-recall` | Broad recall across many past chats by a Haiku subagent |

Copied from the account on the date the template was made; the account versions
may be newer.
